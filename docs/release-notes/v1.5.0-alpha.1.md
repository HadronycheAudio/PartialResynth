PartialResynth is a VST® 3 effect that finds the loudest partials of its input and plays each of them with its own synth voice. **This is a pre-release, for trying the new Partials control.** The latest release stays 1.4.0 until this is confirmed in a host.

## What is new

- **Partials**, a new control in the Analysis section, sets how many of the loudest partials play, each with its own voice, from 5 to 24. More voices resolve a sound into more of its partials, and fewer reduce it to its strongest. Lowering it fades the extra voices out, and raising it gives the waiting partials voices.
- The stereo spread follows the count: the first voice stays in the centre, and the rest go left and right in turn, further out each time. With five, the voices sit where they always did.

## Before you rely on this version

**Nobody has tried this version in a host yet.** The automated tests ran on Windows, macOS and Linux, and compared its output with the output of 1.4.0: wherever Partials is at its default of 5, every sample is identical, bit for bit. The tests do not listen to what 6 to 24 voices sound like.

## Upgrading

Projects saved with earlier versions open as before, and sound as they did: a project saved before this version has Partials at 5. A project saved with this version keeps its Partials setting. This version replaces 1.4.0 on all systems, and the 1.4.0 installer puts 1.4.0 back.

## Installing on Windows

Download `PartialResynth-1.5.0-alpha.1-Setup.exe` below and run it. It replaces any previous version and installs to `C:\Program Files\Common Files\VST3`, where DAWs look by default. You can remove it from the Installed apps page of Windows.

The installer is not code-signed, so Windows shows a warning. To continue, choose **More info**, then **Run anyway**.

## Installing on a Mac

**The Mac version is not yet tested in a real host on a real Mac.**

1. Download `PartialResynth-1.5.0-alpha.1-macOS.pkg` below.
2. Double-click it. macOS refuses to open it the first time, because Apple did not sign the installer:
   - On macOS 14 or earlier, Control-click the file, choose **Open**, then **Open** again.
   - On macOS 15 or later, click **Done**, then open **System Settings**, go to **Privacy & Security**, scroll down, and click **Open Anyway**.
3. Follow the installer, which asks for your password. It puts the plug-in in `/Library/Audio/Plug-Ins`, where hosts look.
4. Restart your host.

## Installing on Linux

There are two downloads, and you can have both:

- `PartialResynth-1.5.0-alpha.1-Linux-x86_64.tar.gz` is the VST 3.
- `PartialResynth-1.5.0-alpha.1-Linux-x86_64-LV2.tar.gz` is the LV2.

1. Extract the downloads into the folders where hosts look:
   ```bash
   mkdir -p ~/.vst3 ~/.lv2
   tar -xzf PartialResynth-1.5.0-alpha.1-Linux-x86_64.tar.gz -C ~/.vst3
   tar -xzf PartialResynth-1.5.0-alpha.1-Linux-x86_64-LV2.tar.gz -C ~/.lv2
   ```
2. On Debian or Ubuntu, install the libraries that they need:
   ```bash
   sudo apt install libxcb-cursor0 libxcb-util1 libxkbcommon-x11-0 libcairo2 libpango-1.0-0 libpangocairo-1.0-0
   ```
3. Restart your host. If it does not find PartialResynth, rescan for plug-ins. In REAPER, add the `~/.lv2` folder under **Preferences**, **Plug-ins**, **LV2/CLAP**.

To remove them, delete `~/.vst3/PartialResynth.vst3` and `~/.lv2/PartialResynth.lv2`. To upgrade, delete those folders first, then extract the new version.

The tarballs are not signed.

## Requirements

- Windows 10 or later, 64-bit, macOS 10.15 or later, or x86_64 Linux with glibc 2.34 or later, as on Ubuntu 22.04, Debian 12 or newer
- A VST 3 host, an LV2 host on Linux, or an Audio Unit host on a Mac. PartialResynth is developed for Cubase, and was tried briefly in one other host, REAPER on Linux. On Linux, the host must embed plug-in windows through X11.
